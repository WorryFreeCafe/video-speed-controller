# 🎬 Video Speed Control — 视频播放速度控制扩展

> 一款轻量级浏览器扩展，用于在 YouTube 和 Bilibili 上自由控制 HTML5 视频播放速度。

**版本:** 1.1  
**Manifest:** MV3 (Manifest V3)  
**支持平台:** YouTube · Bilibili

---

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| **速度范围** | 0.1x – 4x，支持精细调节（步进 0.05x） |
| **迷你面板** | 页面右下角悬浮小面板，默认显示，包含 **−** 按钮、**数字编辑框**、**+** 按钮 |
| **完整面板** | 展开后提供滑块、数字输入、加减按钮等完整控件 |
| **数字编辑框** | 迷你面板和完整面板均支持直接输入数字，精确设置播放速度 |
| **Popup 弹窗** | 点击浏览器工具栏的扩展图标，即使页面面板关闭也能调速 |
| **页面面板恢复** | Popup 中可一键恢复被关闭的页面悬浮面板 |
| **智能注入** | Popup 调速消息发送失败时自动重试注入 content script |
| **SPA 适配** | 完整适配 YouTube 和 Bilibili 的单页应用导航（pushState / replaceState / popstate） |
| **动态视频检测** | MutationObserver 监听 DOM 变化，视频加载后自动创建面板 |
| **状态持久化** | 记住面板状态（展开 / 迷你 / 关闭），跨页面保持 |
| **键盘友好** | 数字输入框支持 Enter 确认，聚焦时自动全选 |

## 🚀 安装方法

### 开发者模式安装（推荐）

1. **下载代码**

   ```bash
   git clone <repo-url>
   # 或直接下载 ZIP 并解压
   ```

2. **打开扩展管理页面**
   - Chrome / Edge / Brave：地址栏输入 `chrome://extensions` 并回车

3. **启用开发者模式**
   - 页面右上角切换开关 → **开启**

4. **加载扩展**
   - 点击 **「加载已解压的扩展程序」**
   - 选择项目文件夹（包含 `manifest.json` 的目录）

5. **完成！**
   - 扩展图标会出现在浏览器工具栏中
   - 打开 YouTube 或 Bilibili 视频页面即可看到迷你面板

## 📖 使用指南

### 迷你面板（默认视图）

打开视频页面后，右下角会自动出现迷你面板：

```
[ − ] [ 1.00x ] [ + ] [ ▲ ]
```

| 控件 | 操作 | 效果 |
|------|------|------|
| **−** 按钮 | 单击 | 速度降低 0.05x |
| **数字编辑框** | 直接输入数字 + Enter | 精确设置播放速度 |
| **+** 按钮 | 单击 | 速度增加 0.05x |
| **▲** 按钮 | 单击 | 展开完整面板 |

> 💡 在数字编辑框中双击或聚焦可全选当前值，方便快速输入。

### 完整面板

点击迷你面板右侧的 **▲** 展开完整面板：

```
┌─────────────────────┐
│  播放速度      [–] [✕]│
│                     │
│       2.00x         │
│  [═══════●═══════]  │
│                     │
│  [ − ] [2.00] [ + ] │
│                     │
│  关闭或收起后...     │
└─────────────────────┘
```

| 控件 | 操作 | 效果 |
|------|------|------|
| **滑块** | 拖动 | 0.1x – 4x 连续调节 |
| **数字输入框** | 输入 + Enter | 精确速度 |
| **− / +** 按钮 | 单击 | ±0.05x 微调 |
| **–** 按钮（标题栏）| 单击 | 收为迷你面板 |
| **✕** 按钮 | 单击 | 关闭面板 |

### 浏览器工具栏弹窗

点击浏览器右上角的扩展图标，打开 Popup 控制面板：

- **即便页面面板关闭**也能在这里调速
- 点击 **「🔄 恢复页面上的速度面板」** 可重新显示页面悬浮面板
- Popup 会自动尝试读取当前页面的视频速度

### 支持的网站

| 网站 | URL 匹配 |
|------|----------|
| YouTube | `*://*.youtube.com/*` |
| Bilibili | `*://*.bilibili.com/*` |

## 📁 项目结构

```
youtube-speed-control/
├── manifest.json     # 扩展清单文件（Manifest V3）
├── content.js        # 内容脚本 —— 注入视频页面，渲染悬浮面板
├── popup.html        # 浏览器工具栏弹窗（HTML + CSS）
├── popup.js          # 弹窗交互逻辑
├── icon.png          # 扩展图标
└── README.md         # 本文件
```

### 各文件职责

| 文件 | 说明 |
|------|------|
| `manifest.json` | 声明扩展权限、content script 匹配规则、popup 入口 |
| `content.js` | 注入到 YouTube / Bilibili 页面，负责：创建迷你 & 完整面板、调速逻辑、SPA 导航适配、视频动态监听、接收 popup 消息 |
| `popup.html` | 扩展工具栏弹窗的 UI 结构 |
| `popup.js` | 弹窗交互：速度调节、恢复面板、fallback 注入 content script |

## 🔧 技术实现

### 核心设计

```
┌──────────────┐    chrome.runtime.sendMessage    ┌──────────────┐
│  popup.js    │ ◄──────────────────────────────► │  content.js  │
│  (弹窗面板)   │      speed / showPanel / getSpeed  │  (页面脚本)   │
└──────────────┘                                    └──────────────┘
                                                          │
                                                    ┌─────┴─────┐
                                                    │  页面 DOM   │
                                                    │ ┌────────┐ │
                                                    │ │ 迷你面板 │ │
                                                    │ │ 完整面板 │ │
                                                    │ └────────┘ │
                                                    └───────────┘
```

### 关键机制

1. **双面板架构**: 迷你面板 (`.ysc-mini`) 和完整面板 (`.ysc-panel`) 共存于同一个 Shadow-root-free DOM 节点下，通过 `data-state` 属性（`expanded` / `minimized` / `closed`）切换显示。

2. **动态视频检测**: 使用 `MutationObserver` 监听页面 DOM 变化，当检测到 `<video>` 元素时自动创建面板并同步速度。

3. **SPA 导航适配**:
   - YouTube: 监听 `yt-navigate-finish` 事件
   - Bilibili: 劫持 `history.pushState` / `history.replaceState` + 监听 `popstate`
   - 通用: 监听 `hashchange`

4. **智能回退注入**: Popup 发送调速消息失败时（如 content script 未注入），自动调用 `chrome.scripting.executeScript` 注入脚本后重试。

5. **防抖处理**: 短时间内多次 SPA 导航触发使用 `setTimeout` 防抖，避免重复创建面板。

### 所需权限

| 权限 | 用途 |
|------|------|
| `activeTab` | 向当前标签页发送调速消息 |
| `scripting` | 程序化注入 content script（fallback） |

**不收集任何数据，不发起任何网络请求，不追踪用户。**

## 🧪 开发与调试

### 修改代码后

1. 编辑源文件
2. 打开 `chrome://extensions`
3. 点击扩展卡片上的 **刷新图标** 🔄
4. 重新加载视频页面（或刷新已打开的页面）

此项目为纯原生 JavaScript，无需编译或打包，直接加载文件夹即可使用。

## ❓ 常见问题

### Q: 页面打开后没有看到迷你面板？

1. 确认当前页面是 YouTube 或 Bilibili 的视频页面（非首页/搜索页）
2. 等待视频加载完成——面板会在视频元素出现后自动显示
3. 检查是否之前关闭了面板——点击扩展图标 → 点击「恢复页面上的速度面板」
4. 尝试刷新页面

### Q: 点击扩展图标调速时报错「请在 YouTube 或 Bilibili 视频页面使用」？

1. 确认当前标签页是 YouTube 或 Bilibili 的视频页面
2. 等待页面完全加载后再操作
3. 尝试刷新页面后重试
4. 如果问题持续，在 `chrome://extensions` 中刷新扩展

### Q: 数字编辑框输入后没反应？

- 输入数字后需要按 **Enter** 键或让输入框**失去焦点**才会生效
- 速度范围限制在 0.1x – 4x 之间，超出范围会自动修正

### Q: 如何更改默认步进值？

- 编辑 `content.js` 和 `popup.js` 顶部的 `STEP` 常量即可
